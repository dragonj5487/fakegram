# 페이크그램 · 디자이너의 7주

인스타그램 형태의 가상 SNS에서 디자이너의 7주를 경험하는 웹 게임입니다.
회사명은 디컨, 대표는 윤하은입니다.

## 게임 흐름

공고 지원 → DM 대화 → 자료 수집·시안 작업 → 시안 전달 → 수정·승인 → 게시 → 퇴사

- 7주, 총 8개 업무. 4주 차에는 컵홀더와 유리창 시트지를 연속 진행합니다.
- 기존 사건 순서와 퇴사 결말을 유지합니다. 답장 초안의 말투·범위·일정에 따라 짧은 반응이 달라집니다.
- 회사·대표 프로필, 주차별 스토리 7개, 회사 및 가상 주변 인물 게시물 21개를 탐색할 수 있습니다.
- 미래 주차의 콘텐츠는 미리 공개하지 않습니다. 홈은 이번 주 소식, 프로필은 지나온 소식의 아카이브입니다.
- 새 프로필 소개·스토리·게시물은 게임 연출이며, 주변 인물은 가상 인물로 표시합니다.
- DM에서 전체 대화 내용과 첨부 자료 이름을 검색합니다.
- 주차별 회고에서 게시한 작업을 확인하고 전체 대화 검색으로 이동합니다.

## 자동 저장

진행 상황, 시안, 도착 대기 중인 메시지, 작성 중인 답장, SNS 반응·댓글, 읽은 스토리를 이 브라우저의 localStorage에 저장합니다.
새로고침하면 이어하기 화면이 나타납니다. 새 게임 시작은 기존 기록을 초기화합니다.
다른 브라우저·기기로 동기화되지 않으며, 브라우저 데이터를 삭제하면 기록도 사라집니다.
저장 공간 접근 실패와 손상된 저장 데이터는 화면에 안내됩니다.

## 실행과 검증

Node.js 24 이상 권장.

```sh
npm ci
npm run dev
npm test
npm run build
```

개발 주소: http://localhost:3000/fakegram/

공개 플레이 주소: https://dragonj5487.github.io/fakegram/
GitHub의 main 브랜치에 수정 내용을 올리면 테스트·빌드 후 GitHub Pages에 자동 배포합니다.

React 18, Vite, Tailwind CSS, Lucide 아이콘을 사용합니다.
테스트는 Node 내장 테스트 러너와 jsdom을 사용합니다.
게임 전체 진행, 저장·복원과 실패 처리, 콘텐츠 해금, 대화 검색, 답장 반응, React 화면 연결을 검증합니다.
jsdom 테스트는 실제 브라우저의 시각적 레이아웃·포커스 동작을 대체하지 않습니다.
참고 사진은 외부 Unsplash 이미지를 사용합니다.
