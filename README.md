# 🌌 JCJ TEAM - 팀 소개 인터랙티브 웹사이트

> **Live Demo**: [https://dragonj5487.github.io/jcj-team/](https://dragonj5487.github.io/jcj-team/)

미래지향적 모노크롬 테마와 Three.js 기반 3D 인터랙션을 결합한 JCJ 팀 소개 웹사이트입니다.

---

## ✨ 주요 기능
- **3D 인터랙티브 큐브**: 마우스 드래그 및 물리 인터랙션이 적용된 Three.js 3D 큐브
- **인터랙티브 파티클 / 성좌 효과**: 큐브와 텍스트 주변의 딥 스페이스 파티클 흩어짐 효과
- **팀원 프로필 카드**: 뒤집기(Flip) 애니메이션 및 상세 모달 지원 (JUNG, CHOI, JEON)
- **반응형 디자인**: 다양한 화면 크기에 최적화된 모던 UI

---

## 🛠️ 기술 스택
- **Frontend**: React 18, Vite 6
- **3D Graphics**: Three.js
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (GitHub Actions)

---

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 확인할 수 있습니다.
